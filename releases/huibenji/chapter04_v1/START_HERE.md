# 第四回制作入口

先读 DIRECTOR_AND_PRODUCTION_PACK.md 看六段安排，再读 audio/MUSIC_PLAN.md，最后按 prompts/H01–H06.txt逐段生产。

1. 角色仍用仓库既有便装母版；潘慧不是长脸，保留自然饱满脸颊、含笑眼和嘴角下方小痣，不套用被用户否决的封面脸。
2. 梦图原文件见本包共享assets路径；H01的4–7、9–12、15–18秒在剪映插入原图，不让模型重绘聊天字样或未知身份。三图均3秒。
3. 先补四类必要静帧：床侧睡衣/惊醒；客栈上午光；小阮与石台；松下起始/放琴/相携。assets.json中的null表示未生成，不能当作可上传文件。可先做H01–H03对白试片，涉及新场景仍先核图。
4. 实际曲源只需提供一次：希望使用的《卜卦》伴奏，加同版带人声示范或当年合唱原音。制作方完成裁段与校准，无需用户自行剪成30秒。仅有伴奏时还需获得/制作同节奏导唱。人物音色MP3已收，不必重传。
5. H01末4秒→H02；H02末4秒→H03；H03末4秒→H04。H04→H05→H06优先同项目有声续写。上传独立视频参考时只用上一任务新增的30秒，不能用累计60秒文件。
6. 若返回的是累计90秒长片，采用整片，不能再把已包含的前段重复拼进去。跨任务尾帧只作状态参考，不在成片重复冻结1秒。
7. 每条Prompt低于2000字符，单独复制TXT即可。H04–H06为原生唱声路线；若采用锁定30秒导唱，把Prompt音频规则替换为“音频1是本段完整混合导唱，严格依其说唱人和时序，无额外音色样本”，移除旧音频2/3说明。
8. 每段只验真实风险：身份与美人痣、谁唱谁动嘴、歌曲首中尾字、琴的放稳与腾手、清唱时伴奏是否真停、吻前是否已停唱。关键问题失败只重制对应4–8秒或使用所在平台实际提供的局部编辑；不要一次重抽全章。
