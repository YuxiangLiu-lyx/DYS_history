# 第四回制作入口 · 草坡浪漫版

**第四回《梦里惊前尘，松间诉衷情》现为7×30秒，共210秒。每场一个独立ZIP，入口 [SCENE_FILES.md](SCENE_FILES.md)。**

先按 [ORDERED_INPUTS.md](ORDERED_INPUTS.md) 的H01→H07顺序制作。每场先复制自己的Prompt，再按编号上传本场图片、音频与前段视频；每包内都有原素材和独立清单。不要把整本导演稿粘进2000字输入框。

1. H01/H02完整保留，H03对白未改。三梦仍按图4密集弹幕、图5求婚、图6打码聊天，在4–7、9–12、15–18秒各3秒，保留原遮挡与马赛克。生成失真时只保真替换三个梦窗口。
2. H03后10秒起采用新巨大迎客松夕阳草坡；旧石台、石板地、扶腰相携及舞步关键帧退出本版。孙在18米外先停步看她，H04边轻拨边近至7米，H05对唱近至1.8米，H06唱毕把阮放孙身侧画左后方约半步、双方靠近路线之外的软草地，至1.2米相望。H07独立30秒给目光、停顿、两次吻及最后大全景。
3. 每场图片1/2锁人物脸，景图锁巨大树冠、柔软草地和夕阳，乐器图锁朱漆金纹阮，手持图锁孙衣服与琴尺寸；关键帧只定对应段初末构图。潘短圆脸及嘴角下方、与玉簪同侧的小痣不能改。实际文件/候选状态见 `assets.json`；规划图不是真实视频帧。
4. H01末4秒→H02；H02末4秒→H03；H03末4秒→H04。H04→H05→H06优先同项目有声延长，每次只提供上一任务新增30秒，不能上传累计60/90秒。H06末4秒→H07，接无歌声环境与已落地的琴；不重演放琴、不重新起乐。
5. H04–H06歌曲音频1尚缺，不能把声线样本前移占位。原生路线：曲参≤22秒＋孙4秒＋潘4秒；精确母带路线：只上传本段完整30秒混合导唱，不再叠加声线，Prompt对应删去音频2/3说明。H07不上传歌或声线，只有环境、呼吸与衣料。
6. 已有真人说话样本无需重传。本次没有收到实际《卜卦》伴奏或孙潘演唱录音。选定曲源后由制作方裁参考与校准句尾；纯伴奏没有逐字口型时钟，不能称已经对上真歌。T2尾的停琴/退伴奏按真实末拍收束，旧固定淡出秒点不再强套。
7. 新图先看脸、巨松尺度、距离和持/放琴。视频再看唱者口型、听者不代唱、手指、落琴因果、清唱是否残乐、吻前停顿、两次吻是否穿模。只修有问题的短镜头；不为极小瑕疵重抽全部。
