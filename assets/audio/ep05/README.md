# 第五回音色短参考

两个4秒WAV从已收到的用户原MP3裁切，减1dB留余量，未做换声或生成演唱。男样本取原文件1.65–5.65秒；女样本取2–6秒。原MP3保留，来源、转换、时长与SHA-256见manifest.json。

用途只限音色条件，不复述说话内容，不拿说话的节奏驱动歌词口型。已检查完整解码、采样格式、时长、峰值；尚未试听确认样本是否纯净单人。上传前听这两条即可，若含杂音/别人插话，换取原文件内另一段4秒，不要求重录整套声音。

R02/R03分别用同一对短样本＋本段《卜卦》曲源最多22秒，合计不超过30秒。歌曲文件尚未收到；这里的WAV不是《卜卦》导唱，也不代表声音模仿已成功。
