潘慧的少量超满刻度样本可能来自 MP3 重建过冲，**不能仅凭这项数值认定存在可听削波**。本轮保留她的原 MP3；若实际导入后听到失真，应先检查解码及输入增益，再决定是否另存降低增益的派生版本，并保留原件和处理记录。

这里测的是样本峰值，不是过采样真峰值；RMS 不是 LUFS。低电平检测不等于语音检测。没有低电平区间也不等于全程为纯净人声。

本轮没有实际试听或语音转写工具结果。清晰度、背景音乐、多人重叠、说话人数、是否截断音节、适合的纯净片段及可听削波均在清单中记为 `null`，没有把技术检查写成听感验收或独立身份核实。

可重复运行 `python assets/audio/voice_references/inspect_voice_references.py`，用本地 ffmpeg、ffprobe 与 NumPy 重建测量清单；该脚本只读 MP3 并写 `manifest.json`。

## 在 Seedance 任务中使用

1. 按当前任务清单，只上传该任务里**确实开口说话**的主角音色；角色仅沉默出镜时无需上传其声音。路人和史官不冒用这些真人参考。
2. 音色参考使用入口独立的音频槽位，不作为“背景图”计数。本轮用户报告的是图片容量和视频时长；音频文件数量、总时长、可选格式及是否支持音色绑定，仍以实际入口为准，不能从“50 张图”推断音频无限。
3. 每次绑定实际上传的标签。比如某任务上传笑皇、小腿、潘慧三段，必须在该任务中明确实际的 `@音频1`、`@音频2`、`@音频3` 对应谁；不能把资产 ID 当作平台已经存在的上传引用。未上传的标签必须删去。
4. 若入口不接受完整长度，不随便从任意秒数截取。先实际听取样本，选同一人独说、无音乐和重叠、首尾不截字的区间，另存派生版本，记录源文件 SHA、`source_in/out`、处理参数及新 SHA。原 MP3 始终保留。
5. 先核对原文和说话人，再验收嘴唇与声音首、中、尾的同步。原声样本只提供音色身份；新台词的音素、节奏和口型必须由本次台词一起生成。**音色相似不能替代口型同步。**

可并入完整任务 Prompt 的声音约束（将方括号换为任务清单里的真实标签与角色）：

```text
[实际音频标签] 仅绑定 [角色名] 的音色身份。使用参考中该人的音色特征，为本 Prompt 列出的古装台词重新生成声音与同步口型；台词文字和时段以本 Prompt 为准。不要复读原声样本的内容，不要复用样本中的背景音乐、其他人的声音或现代环境声。不要将该音色分配给其他人物。当前说话者可见时嘴唇须与自己台词的音节同步；反应镜头中的听者保持闭口，不替画外说话者或史官发言。除列出的台词外不加话、不笑场。样本自身的语速与停顿不覆盖本场表演节奏。
```

真人音色保持可辨认，古装表演依角色调整：笑皇年轻有威严，小腿利落谨慎，魏笑平静傲慢，潘慧温柔自然、含笑有主见。不能把“温婉”变成通用女播音声，也不把原素材可能包含的现代情绪机械带进剧中。西卡音色预存，不因此改变本集无对白的事实。

## 保存与验收边界

本目录中的 `seedance_upload_verified=false` 表示这些文件尚未由助手实际上传 Seedance 并验证；`model_voice_similarity_verified=false` 表示没有生成样本可供听感比对。生产包里的引用分配是执行计划，不应被写成平台任务已成功。

将来生成后，应在对应 take 记录实际音频上传顺序、文件 SHA、入口显示名、原始视频、采用区间、最终台词及首中尾口型偏移。新录音改变台词节奏时，需要重新对口型或按已验证支持的音频驱动方式重生成；不能简单覆盖声音后称为已修复。
