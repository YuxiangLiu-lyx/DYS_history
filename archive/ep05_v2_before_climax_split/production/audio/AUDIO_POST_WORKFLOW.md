# EP05 v2 同期声与最少后期

R01仍按四句既有对白、对应原声音色生成同期画面。R02/R03改为原生歌声+伴奏+环境声，generate_audio=true；旧版静音后配规则已归档，不再用于当前任务。

- 歌曲参考负责旋律、词与节奏；两条4秒人物样本只借音色，不复读聊天。每段歌曲最长22秒，总音频输入最多30秒。
- 歌声与嘴型由同次生成匹配；仍需逐句听看旋律、词序、男女归属和首中尾口型，不因存在音轨就写通过。
- R03必须引用R02完整有声0–30秒执行新增30秒连续延长，不能静音或只传尾帧代替声画上下文。
- 官方API生成声轨为单声道混合音轨，其他入口以实际返回核验，不保证分轨；优先保留原生合格歌声和音乐，不默认后配原声。
- 轻笑是本剧新表演安排，不称实际原录音复刻；相吻前演唱收束，吻中仅尾奏和环境声。
- 用户只需提供一次实际曲源，我们裁两条歌曲参考并记录原音源SHA、取段EDL与实际拍点；不要求用户自己换声或先做男女导唱。
- 保存实际文件、模型入口、参数、采用区间、音画偏移和审阅日期。补拍只针对真实失败部位；不能用配音盖住闭嘴而标为修复。
