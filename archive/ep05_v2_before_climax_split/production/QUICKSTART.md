# EP05 v2 使用流程

第五回保持90秒：R01客舍议策30秒，R02男唱走近30秒，R03接唱、合唱和相吻30秒。两段歌唱改为Seedance原生生成歌声、伴奏及同步口型；用户无需制作男女导唱、换声或再给整段配歌。

1. **只提供一次实际采用的《卜卦》音频或原视频**，保留歌曲相关段及前后余量即可。可以是歌曲版本，不要求先做成孙潘合唱。当前尚未收到真实曲源；不把歌词网页当音频。
2. 我们据这一个曲源准备R02/R03各不超过22秒的歌曲参考，按真实音乐小节缩短无词间奏、保留完整字头字尾。两段均另附男4秒、女4秒音色，总音频最多30秒。现有两条音色裁片已按独立文件登记；它们不代替歌曲。
3. 沿用现有角色及S15；按生产包审查本次起末构图并补必要关键帧。每段只上传指定5张图，先核嘴角下小痣、便服、左右站位。首尾帧现在是文字描述，不能当作已生成图片。
4. R01剧情、Prompt、四句对白及五镜沿用。R02设置30秒，开启音频生成，上传歌曲与两条音色，复制R02_PROMPT.txt。可选引用R01末3秒松下片（无对白）。**这一次就是正式可采用素材，不另花一次试拍费用。**
5. 听看R02：像不像两人、是否唱真实旋律与词序、嘴是否同步、男方是否只走近约0.6米、结尾是否纯伴奏且潘慧开始回头。合格后保留完整0–30秒原有声音，不要导出成静音片。
6. R03必须以完整有声R02作@视频1，选择连续延长/extend、**新增30秒**，开启音频生成、沿用R02画幅；API使用ratio=adaptive而非强设16:9；同5图，换为R03歌曲参考，仍用同两条4秒音色，复制R03_PROMPT.txt。承接伴奏和转身，不重新起前奏。
7. 若返回的是累计60秒文件，保留这个连续60秒版本，不把R02重复拼一次；若返回仅新增30秒，按真实输出核对头尾后连接。只把R01接在此前面，最后加标题、字幕和AI生成/架空历史二创声明。
8. 保存完整输出、实际曲源与裁剪EDL、角色音色、参数、采用区间和实测问题。需要局部返修时保留上下文，不为小瑕疵重抽整章。

原生声轨可能只有混合音频，不保证分别导出歌声与伴奏。4秒说话样本只能帮助接近本人音色，实际歌唱相似度仍需验收；当前没有Seedance成片，不能保证一次零错误。若当前入口不支持保留音轨的连续延长，先核对可用入口；不要默默改回静音后配或把尾帧声称为有声上下文。
