## 多角度板用途

每板3列2行，从左到右：正面、向画面左转约45度、向画面右转约45度；下一行：侧面、表情1、表情2。西卡与魏笑采用v02，已经定向修正重复转头方向。

这批以整板提供角度及表情审阅，同时保留高清正面、全身独立母版，并非35张独立视角图。用户确认后，正式视频人物Reference优先引用独立母版；需要特定侧面时再生成对应独立图，不把多人或多格板直接送入镜头生成。

## 一致性

同一角色的脸、发型、帽冠、领口、衣料和主色沿母版延续。潘慧夜景仅加披帛；笑皇、西卡、魏笑本回沿用同一服装。原始照片清晰度有限，未有全部真实侧脸，所以生成侧面与表情属于艺术推断，不能视为精确三维扫描。

所有配角面孔原创。孩子此图是健康平静的戏服状态，剧情中的哭泣通过后续表演实现。老人缺口碗跨镜必须沿用。
