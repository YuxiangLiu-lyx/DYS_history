# Seedance接入与项目执行约束 v3

2026-09-22。用户确认实际入口最多5张图片，本项目全部任务按**5张总图片预算**执行；人物、场景、道具、起止状态和可选尾帧均计入。官方模型发布规格不替代用户实际入口，当前清单与校验器不沿用旧7–9图方案，也不用多脸拼板规避。

Seed官方发布文确认原生音视频、多模态参考、视频编辑及延长能力。本项目采用原生同期对白优先；这些能力不保证每次逐字、逐帧成功，也不证明参考音频会严格驱动嘴型。

- 实际模型、声音开关、片长、多参考模式须在账号确认。项目16:9、24fps剪辑，保留源视频原始帧率，改变工程帧率不等于加速播放。
- 图片首末状态是软约束。专用首尾帧、多参考、视频延长、音频驱动能否同时用，以入口为准，不编造接口字段。
- 对白任务明确发言者、嘴型及听者行为，先验同期对白再加音乐。无对白任务禁止口述解释；妇人和史官画外声独立后期加入。
- 提取视频声音只得到原混合音轨，不自动获得角色、环境、音乐的独立stems。分离、变声、对口型修复都须检查实际输出。
- 音频条件生成或专门对口型属于待实测修复选项；无嘴型、错人、错词不能靠简单替换音轨解决。
- 六宫格只供人审，视频使用清单内独立角色图及自然剧情关键帧。G为剪辑段，实际执行G20–G24。
- 真人人像主体参考依官方要求及账号正常验证/授权流程；古装化不作为绕过接入要求的方法。
