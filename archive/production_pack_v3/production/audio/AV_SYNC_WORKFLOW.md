# 第一回声画同步执行流程 v3

日期：2026-09-22。适用当前用户入口：**每次最多5张图片**，包括人物、场景、关键帧和抽出的实际尾帧；不同图片功能不能重复计算配额。剧情、对白、90秒总时长、7个Block及原25项镜头/字卡均不改。

**当前证据范围：用户报告已经生成的视频有无口型和声画不匹配；本轮尚未收到这些原片和音频，不能逐片定位，也没有修复或验收任何成片。**本文件和同目录两份JSON修复的是生产与返修方法，所有实际媒体路径、任务ID和逐句验收先保持空值/未验收。

## 1. 默认制作顺序

1. 先按 `../refs_upload.json` 上传本场≤5张已选图片，逐一核对实际标签。角色、布景、道具能从一张关键帧明确辨认时就复用，不能用六宫格拼图绕开配额；不要把缺失文件写成已上传。
2. 对需要看到嘴的句子，先用当前入口**原生音画同生**：固定说话人、原文、说话时窗和可见口部，让模型一次产生对应表演和声音。仅提示“自然对白”“同步配音”不足以防止听者代说；当前Prompt必须具体写谁开口、谁听、哪些时段是画外声。
3. 原片连同原声原样保存，先查原文、说话角色、嘴是否可见、首中尾是否同步、动作是否保留；确认同期对白可用以后再选择角色音色。图生视频能力、台词提示、音频引用、真正按音素驱动嘴型是不同能力，实际入口支持何种能力须小样验证。
4. 默认保留已经同步的同期对白。若只改音色，优先用**保留原音素顺序、语速、停顿和呼吸节奏**的变声方法，逐句复查；变声可能改变发声起点，不保证零偏移。
5. 如果要换成节奏不同的TTS/演员最终配音，先锁定完整最终音频，再用经实测支持的音频条件视频生成或对口型处理重新生成该说话镜头。只有“参考音频”入口时先验证它是否真的驱动口型，不能当作已支持。**不允许把新配音盖在静止闭嘴人物上当作完成。**若入口无法严格驱动，采用原生同期音，或只重做故障说话镜头。
6. 妇人DLG03和史官DLG14默认独立后期音轨。其余既定场内画外片段可保留同一场原生声音。所有旁白/画外声都不要求可见听者开口；孩子允许自然无字哭声，不增加“爷爷”等台词。
7. 最后再统一环境声、拟音、配乐、字幕。先锁说话表演，再混音；字幕准确不代表声画同步已经通过。

### 同一角色跨场音色：以潘慧E/F为例

先从通过口型和原文检查的潘慧样片里选择一条声线，记录为C05本集目标声线；DLG10（E拒礼）、DLG12和DLG13（F夜窗）都以它为准，情绪从礼貌温和转为私下自然，不改变人物音色身份。若原生E/F或不同take嗓音明显不同，把这些句子都转换到**同一已选目标音色**，使用保留各句原音素时序、语速、停顿和呼吸的变声设置，再对每句首中尾复检。不可只凭相似的音色形容词认定声音连续。

若此方法不能保持同步，就录制/生成同一声线的完整最终对白，对各自可见说话镜重新对口型或采用经过实测的音频条件生成；不得直接把节奏不同的新声盖上去。小腿DLG06/07等跨镜同角色同样处理。

若入口支持音频参考，可附**确实存在、已采用、已记录路径**的角色声线/表演样本，上传后绑定实际音频标签；它仅是声线/表演参考，除非实测证明入口可严格按音素驱动，否则不能保证口型同步。目前没有用户提供的音频，也未生成任何声音文件，所以目标声线文件与可选参考都保持null；不得虚构WAV或声线授权记录。

下面的秒数是**剪辑与验收目标，不能保证模型逐秒精准执行**。源片实测不符时先按实际录音核对，选择可用表演，或定向重做故障镜头；不能把不同步用字幕或不自然变速掩盖。

## 2. 三种时间必须分清

- **global**：90秒最终成片上的绝对时间。
- **block-local**：从该Block成片入点起计，A/B/C/D/E/F/G分别减去0/13/24/34/47/62/75。
- **source**：生成出的完整原片时间，包含为了完整说话保留的头尾余量。D与可选补拍任务不能把source直接当成block-local。

画面为24fps；对白表为精确十进制秒/48kHz音频采样位置。对白起点不必强行取整到视频帧，既定摄影切点则保持原帧。JSON中的数字以左闭右开区间存储。

## 3. C→D必须这样处理

旧方法让D第0秒“已经说到半句”，却没有提供足够的同步源音，容易造成口型乱续、重复“徽州”或新配音接不上。现在D生成**14秒原片**，保留0.5秒画面头余量；成片D仍是13秒。

| DLG07画外句 | 5.7–8.8 | 39.2–42.3 | 小腿说，西卡不代说 |

如果入口只能选15秒，就生成15秒，继续采用相同source0.5–13.5，剩余尾部舍弃；不要把成片D延长。先试听/看实际源片，未落在目标窗口时按故障表处理，不能假设一次生成就准确。

## 4. A、E、F的关键限制

- **A镜02**是老人背后过肩。老人问话口部本来不可见，这不属于“没口型”的故障；不为此增添正脸镜头。官差答话5.7–7.0必须看到嘴，推上臂仍保留。妇人DLG03在镜03画外，老人和孩子不能代说。
- **E镜14/15**分别锁定公子、潘慧开口。过肩前景不能挡住公子嘴，房契不能升到脸前。公子推来、潘慧推回、对方接走的动作状态必须连续；补口型不等于删掉推契动作。
- **F侍女**64–65可见开口，65–67.4说话者在画外，潘慧近景安静听。问题完整录一次，不在65秒重新念后半句。
- **F潘慧**68–69.4是一句整段表演，69秒只换机位，口型和尾音必须接续。70.2–73.6回答时，采用嘴唇/下颌清楚的侧脸角度；直到尾字结束才转回窗外。发丝、手、披帛都不能遮口，嘴角下方的痣保持既定位置。
- 听者可以呼吸、眨眼、轻微表情变化；“闭口听”是禁止替人念词，不能把人物做成僵硬人偶。孩子无字哭声和对应哭泣表情作为单独行为保留。

## 5. 故障定位与最小返修

| 观察到的故障 | 先检查 | 可执行修复 | 不采用的方法 |
|---|---|---|---|
| 整句声音始终提前/滞后同样量 | 开头、中段、句尾偏移是否相同；源音和画面是否来自同一take | 仅平移该句音轨相同偏移，环境底声单独连续；然后首中尾复查。若超出锁定窗口则需重新选片/补拍 | 仅以第一字对齐就宣布通过；整段BGM一起移动 |
| 开头对齐，后半段越来越错 | 变速、变声、重采样、重录停顿、丢帧或可变帧率 | 先还原原生同期音和正确播放速度；必要时正规转恒定帧率并核对PTS。仍漂移则用最终配音重新对口型/只补该镜 | 把不断漂移当恒偏移；分别拉伸每个字来迁就嘴 |
| 句子错字、漏字、重复开头 | 对照锁稿逐字听；尤其C/D、F跨切 | 该说话镜重新音画同生，或锁正确音频后重新对口型。画外句可单独换完整声音 | 仅修字幕；剪掉尾字；在嘴可见处插另一句声音 |
| 听者开口、两人同时念同一句 | 镜头是谁、Prompt谁发声；是否混入旁白驱动 | 锁单说话者和听者闭口，只重做故障镜；画外声后期独立，不用它驱动听者 | 把发声角色改成听者；裁掉本来必须有的反应镜头 |
| 应说话者闭嘴、只有头像推拉 | 是否是本来就画外的句子；需同步时嘴是否看得见 | 可见说话镜不合格则单说话者补拍；保留原动作与镜头时窗。若真实口型处理工具可用，先用最终音频实测 | 静音旧片直接盖配音；加字幕假装在说话 |
| 嘴被头发、手、房契或披帛遮住 | 入句到尾字逐帧查遮挡 | 在原景别/轴线上小幅调脸朝向与动作高度后补拍；仍保持原事件与切点 | 改成全程背面来规避问题 |
| 转音色后不再同步 | 原生音正常、变声后首字/停顿是否变 | 用保留节奏的变声设置或回退同期音；仍不匹配则对口型重做 | 把“声音时长一样”当音素时间完全一样 |
| 画外/旁白听起来不在空间里 | 是否正确区分场内画外与史官叙述；响度/混响 | 老人、妇人、小腿保留对应场所空间感；史官独立叙述声；降低竞争底噪 | 给史官加角色嘴型；旁白与环境一起压到听不清 |
| 首尾正常但切镜后突然重音/双声 | 是否同时开着原片音轨和提取对白；跨切是否生成了两份台词 | 只保留同一个完整句，去掉重复音轨，保留环境底声连续 | 用淡化掩盖两人声/两个“徽州”叠加 |

## 6. 验收和存档

1. 用耳机正常速度看一遍，确认14句逐字正确、角色归属正确、没有新台词/重声、自然停顿和情绪可用。自动语音转写仅辅助。
2. 对每个 `lip_sync_required=true` 的区间，选开头、中间、结尾至少一个清楚发声事件，慢放/逐帧核对嘴唇与声音；开闭口、双唇闭合音等可作锚点，但中文每个字的嘴形并非唯一对应。项目人工验收目标为**误差不超过±2帧（24fps约83ms）且不随时间漂移**，这不是Seedance的平台性能承诺。
3. 同时查身体动作：推臂、推匣、捻米、推契、披帛必须保留，不能以口型合格换成站桩。查潘慧痣、人物身份、听者闭口、侧脸无遮挡与轴线。
4. 独立验C/D与F69秒这两个跨切点：完整句只能一份声音，切点前后口型连续；G所有角色不说旁白。87.3之后没有旁白尾字，90秒结束。
5. 至少保留 `native_dialogue`、`offscreen_dialogue`、`narration`、`ambience_foley`、`music`、`final_mix` 的可恢复轨道；如果平台只给混合声，不把它伪标成干净分轨，记录分离方式及残留，保留未经处理原声。
6. 保存原片、提取声/变声前后声、完整Prompt、实际图片/视频/音频引用、模型入口、takeID、采用源区间和成片区间、每句首中尾误差、验收结论、费用及失败理由。未知值写null；路径应指向能恢复的文件，不能只剩会过期链接。
7. 保持 `EP01_LOCKED_v1.md` 和原90秒时间线不变。更新 `context/STATUS.json`、生成历史、素材索引和校验；按仓库既定同步流程提交GitHub。没有收到并检查成片时只能写“流程已修订，成片待检”。
