# EP05 v3 同期歌声与最少后期

第五回全部是90秒歌曲高潮，无口述对白。客栈及小腿台词只在前章EP04 Q04；本章dialogues为空，dialogue_timing.srt为空，不能继续导入旧E5对白字幕。

1. R01男唱、R02女接唱与原分唱、R03新增双人副歌回唱，均原生生成歌声、伴奏、口型及环境声。相吻前歌声收束，吻中只有尾奏与环境声。
2. 同一曲源裁A/B两种参考，A用于R01和R03，B用于R02且含约2–3秒前奏余量。每次曲段≤22秒、男4秒、女4秒，独立音频总计≤30秒；人物样本只借音色，角色重唱，不叠原唱或样本聊天。
3. R02/R03分别引用上一任务新增30秒的完整有声范围延长。若返回累计60秒，继续时只选新增30秒或使用入口内续写；不能上传整60秒超限，也不能静音。最终若返回累计90秒，直接采用，不重复拼接。
4. 30秒接缝在间奏，60秒在无词桥与副歌句首之间；按真实小节与歌尾调整，不机械删秒或变速。R03的副歌回唱为本剧编排，省去原曲后续另一组主歌，不称原曲完整复刻。
5. 原生混音优先保留。官方API有声输出为单声道，其他入口据文件核验；不保证独立人声、伴奏或SFX分轨。明显重唱/串声/转调返修对应段，轻微无词音量跳变再做最小衔接。
6. 末6.5秒深情相吻前必须已收歌，双方主动靠近、彼此回应；没有边唱边吻或跳位融脸。逐句听看首中尾同步，输出有音轨不等于通过验收。
7. 保存原始输出、新增范围映射、实际源音与裁剪EDL、音色参考、参数和验收结果。现有说话裁片尚未主观试听，真正曲源尚未收到，不宣称声线或口型已锁定。
