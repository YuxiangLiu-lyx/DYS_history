## 2. 先生成同步对白，再混音

1. M01→M02→M03依次生成。每次30秒；先核查实际上传标签、音频角色和同幕景别时间窗。前一幕真实尾帧/视频用于视觉接续时，仅在已生成、已提取且入口支持后绑定，不添加不存在的素材。
2. **12句场内对白与表演原生同期生成**，每句只出现一次。指定谁开口、何时开口、谁闭口听；正常呼吸、眨眼、孩子无字哭泣仍可保留。同期声音中的角色音色从本幕指定样本取，台词只来自锁稿。
3. DLG03妇人和DLG14史官独立后期录制/配音；不把这两句喂给可见角色驱动口型。配角无真人音频时选稳定原创声线，不能用潘慧代侍女、笑皇代史官。纯音频制作使用实际可用配音/录音工具，不假设Seedance有纯音频导出按钮。
4. 保存原始30秒视频与原生完整音轨，逐句查原文、说话角色、嘴是否可见、首中尾同步和既定动作，再决定是否保留该take。参考MP3不直接铺到成片，也不充当最终对白。
5. 原生对白已同步但音色不一致时，优先转换到同一个角色样本的音色，保留原音素顺序、时值、停顿、呼吸；之后仍需重新听看首中尾。只说“换音色不改时长”不能证明音素时序没变。
6. 若改用不同节奏的TTS/演员新配音，先锁最终完整声音，再使用经实测可用的音频条件视频生成或口型处理重新生成该说话镜。**不能给闭嘴人物覆盖新声后称为修复**，也不能把一个整句拆为两次生成后机械拼接。
7. 对白稳定后才做环境音、拟音、配乐、字卡和字幕。姓名、地名、密报正文、片尾标题统一在剪辑时排版，不要求视频模型生成准确汉字。混音时先照顾对白可懂度，保持场所空间感。

## 5. 故障定位与最小返修

| 故障 | 检查依据 | 执行办法 |
|---|---|---|
| 整句声音固定提前/滞后 | 开头、中段、句尾是否同量偏移；音画是否来自同一take | 仅移动该句音轨相应量，环境声分开；首中尾复查。若因此超出锁定说话窗口则需重新选片/补拍。 |
| 开头对，后段逐渐偏 | 变速、变声、重采样、丢帧、可变帧率/PTS | 先恢复原生同期音和正确播放速度；必要时正规转恒定帧率再验。仍漂移则重新对口型/补故障镜，不能只平移开头。 |
| 说话者不张嘴或只有静图推拉 | 对照可见/画外合同，确认应开口的是谁 | 优先时间戳局部编辑该可见发言镜，明确台词与嘴部；仍不合格则单说话者短补拍。保留推搡、推银匣、捻米、推契或披帛。 |
| 听者跟嘴或两人同说 | 对照说话者ID与画外片段，检查音频槽串人 | 定向修听者/说话镜，指定唯一发言者和听者闭口；纯画外声后期独立，不能给听者加口型。 |
| 错字、缺字、重复句头 | 对照锁稿逐字听，特别是三处跨镜 | 可见说话镜重新同期生成或锁正确新声后重新对口型；画外句可换完整声句，字幕修正不足以解决。 |
| 复制样本台词或现代口头禅 | 样本内容是否被当成待朗读正文；音频标签角色是否正确 | 明确“只取音色、不播放样本、唯一文本”；只重做相应说话镜/声句。原声文件不得直接混入成片。 |
| 声音串成另一角色或潘慧跨幕不同人 | 核对本幕音频标签、样本与说话人绑定 | 纠正槽位后局部重生；若嘴型好，只保时序换到同一正确样本声线并复检，不能靠文字形容词认定同声。 |
| 嘴被发丝、纸张、袖子遮挡 | 从首字到尾字逐帧看遮挡 | 在既有景别/轴线内稍调脸朝向和手部高度后局部补拍；不改成全背影逃避，也不删推契/披帛。 |
| 变声音色后不同步 | 比较变声前后音素起点和停顿 | 回退正确同期声或使用保时序变声；改变节奏则重新对口型，时长相同不等于逐音素同步。 |
| 切镜后重音、双声、句头重复 | 原片声和提取声是否同时播放；同一句是否生成两份 | 只保留一条完整声句；移除重复的人声并连续铺环境声，不能用淡化隐藏双声。 |
| 旁白像从角色嘴里发出或空间不对 | 场内画外与史官是否分轨、混响和响度是否合适 | 场内声保留该空间感；史官为独立叙述，所有画面角色不回应它；音乐低于对白。 |

## 6. 验收和保存

1. 用耳机正常速度听看，14句原文正确、说话人正确、无额外语句/重声；原音样本内容、背景音乐和直播底噪没有被复述或混入。以原始视频检查，转写/字幕只作辅助。
2. 每个可见发言区间至少检查首、中、尾一个清楚发声事件，结合嘴唇开合、下颌与双唇闭合音。项目人工目标为 **±2帧（24fps约83ms）内且不持续漂移**，这是目标，不是Seedance性能保证；并以正常播放是否自然作判断。
3. 同时查人物动作、眼神、接触、背景人物和物件：不能以口型合格换成站桩；潘慧痣、玉簪、披帛、手与房契持续一致。M03尾段小腿读密报是默读，魏笑、笑皇、西卡和潘慧不念史官词。
